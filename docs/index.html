功能特性

四档步长移动

Alt 系组合键 + 方向键，四档步长可调，按住连续移动，避开系统与输入法冲突。

三键模拟点击

Ctrl+Alt+1 / 2 / 3 一键模拟左键、中键、右键点击，全部走 SendInput。

连点器

次数、间隔、键位全可设，Ctrl+Alt+4 一键启停，间隔 0 为极速模式。

坐标与定点移动

鼠标坐标实时显示，输入坐标一键跳转，也可取当前坐标快速填入。

托盘常驻

关闭窗口收进托盘，Ctrl+M 随时呼出，单实例运行不重复。

设置持久化

步长、连点器参数自动保存，重启不丢，轻量 JSON 存储。

快捷键

微小移动 Ctrl+Shift+Alt+方向键 连点器启停 Ctrl+Alt+4
